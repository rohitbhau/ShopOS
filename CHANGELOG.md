# Changelog

All notable changes to ShopOS will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Initial project setup
- Multi-tenant architecture with RLS
- Offline-first sync engine
- Dynamic low-code form renderer
- Phone OTP authentication
- Product & inventory management
- POS billing system with offline support
- Invoice PDF generation with UPI QR
- Customer ledger management
- Reports & analytics
- Staff management with role-based permissions
- Subscription billing via Razorpay
- WhatsApp notifications
- Admin dashboard with low-code builder
- Workflow automation engine
- 6 shop templates (retail, pharmacy, salon, restaurant, boutique, repair)
- Multi-language support (English, Hindi, Marathi, Tamil, Telugu)
- Thermal printer support (58mm/80mm)
- Barcode scanning
- CSV import/export
- Trial period management (14 days)
- Feature flags system
- Audit logging

### Security
- SQLCipher encryption for local database
- Row-level security (RLS) for all tenant data
- JWT-based authentication with custom claims
- Webhook signature verification
- Encrypted local storage for sensitive data
